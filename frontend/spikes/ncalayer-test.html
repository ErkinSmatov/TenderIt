PORT VERIFICATION REQUIRED — Read Before Testing

Before connecting, confirm the actual NCALayer listening port by running:
• macOS/Linux: netstat -an | grep LISTEN | grep -E "13579|14579"
• Windows (PowerShell): netstat -ano | findstr "13579 14579"

The URL inputs below default to wss://127.0.0.1:13579 (community-confirmed as of NCALayer 2.x) but your installation may use 14579. If neither port shows in netstat, run netstat -an | grep LISTEN (all ports) and locate the NCALayer process. Test BOTH ports if unsure.

Self-Signed Certificate Trust (required for wss://)

If the wss:// connection fails immediately with an error, NCALayer uses a self-signed certificate that the browser does not trust yet. To trust it:
1. Open https://127.0.0.1:13579 (or your confirmed port) in the same browser.
2. Click Advanced → Proceed to 127.0.0.1 (unsafe).
3. Close that tab and retry the WebSocket connection below.
(This must be done once per browser profile per NCALayer installation.)
