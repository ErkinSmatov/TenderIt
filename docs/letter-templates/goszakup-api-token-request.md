## Заявление о предоставлении токена доступа к OWS API v3 (ows.goszakup.gov.kz)

Уважаемые коллеги,

[ПОЛНОЕ НАИМЕНОВАНИЕ ОРГАНИЗАЦИИ] (далее — «Заявитель»), действующая в лице [ДОЛЖНОСТЬ И ФИО РУКОВОДИТЕЛЯ, например: Директора Иванова Ивана Ивановича], действующего на основании [УСТАВА / ДОВЕРЕННОСТИ № __ от __.__.____], обращается с настоящим заявлением о предоставлении API-токена для программного доступа к сервису OWS v3 портала государственных закупок Республики Казахстан.

### 1. Основание для запроса

В соответствии с условиями использования открытого API портала «Государственные закупки» (https://goszakup.gov.kz/ru/developer/ows_v3) просим предоставить токен Bearer-аутентификации для доступа к GraphQL-эндпойнту:

```
https://ows.goszakup.gov.kz/v3/graphql
```

### 2. Цель использования

Токен будет использован исключительно для:

- Программного поиска и мониторинга тендерных объявлений (TrdBuy) в интересах Заявителя;
- Получения актуальных данных о закупках с целью автоматизации участия в государственных закупках через разрабатываемый Заявителем программный продукт;
- Подачи заявок на участие в тендерах через официальный API в соответствии с действующим законодательством Республики Казахстан.

Сторонним организациям доступ к API-токену предоставляться не будет. Токен будет храниться в защищённом хранилище секретов и не будет фиксироваться в открытом исходном коде программного продукта.

### 4. Описание программного продукта

Разрабатываемый продукт — **[НАЗВАНИЕ ПРОДУКТА]** — представляет собой веб-приложение для автоматизации поиска тендеров и управления документами при участии в государственных закупках Республики Казахстан. Продукт предназначен для субъектов малого и среднего предпринимательства. Интеграция с API портала «Государственные закупки» является ключевым компонентом данного продукта.

### 5. Обязательства Заявителя

Заявитель обязуется:

1. Соблюдать условия использования API портала «Государственные закупки», опубликованные по адресу: https://goszakup.gov.kz/ru/developer/ows_v3
2. Не передавать API-токен третьим лицам и не публиковать его в открытых источниках.
3. Не превышать допустимые лимиты запросов (rate limits), установленные правилами API.
4. Незамедлительно уведомить АО «Центр Электронных Финансов» в случае компрометации токена.
5. Использовать API исключительно в законных целях, предусмотренных Законом Республики Казахстан «О государственных закупках».
