<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → /api/company/profile | Auth-gated; BIN is PII under KZ localization rules |
| FastAPI → Postgres | Parameterised queries; one-to-one constraint at DB level |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-05-01 | Spoofing | Injecting non-BIN values (IIN, random 12-digit) | mitigate | Backend field_validator runs validate_bin (checksum + position 5 ∈ {4,5,6}); 422 returned on failure (Pitfall 5) |
| T-02-05-02 | Tampering | Cross-user profile modification | mitigate | upsert keyed on current_user.id (from JWT-validated dependency); user_id is server-derived, never accepted from body |
| T-02-05-03 | Information Disclosure | Profile data leakage in logs | mitigate | No structured logging in this phase; BIN is not in error responses; CompanyProfileResponse contains only the requester's own data (auth scoped) |
| T-02-05-04 | Elevation of Privilege | Reading another user's profile | mitigate | GET /api/company/profile selects WHERE user_id == current_user.id; no path parameter for user_id; impossible to address another user |
| T-02-05-05 | Tampering | Race condition: two PUTs creating duplicates | mitigate | DB unique constraint on CompanyProfile.user_id; select-then-update path normally wins; if race occurs, IntegrityError is raised — wrap upsert in try/except and retry select-update; alternatively rely on the brief window being acceptable for MVP |
| T-02-05-06 | Information Disclosure | KZ data localization (PII: БИН) leaving KZ infrastructure | mitigate | Storage is local Postgres only — no third-party PII processor in this phase; documented constraint already in CLAUDE.md |
</threat_model>
