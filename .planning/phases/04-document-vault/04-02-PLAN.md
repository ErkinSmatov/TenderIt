<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → API | Браузер шлёт multipart upload и JSON; недоверенный вход |
| API → MinIO | Backend стримит файл и генерирует pre-signed URL |
| API → PostgreSQL | Метаданные с FK на users |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Information Disclosure / Tampering | GET url, PATCH, DELETE по doc_id | mitigate | `get_user_document` фильтрует по user_id; чужой → 404 (не 403) |
| T-04-02 | Denial of Service | POST /documents | mitigate | `file.size > 20MB` проверяется ДО put_object → 413 |
| T-04-03 | Information Disclosure | object_key / MinIO | mitigate | uuid4 в ключе; бакет приватный; доступ только через pre-signed URL TTL 15 мин |
| T-04-04 | Spoofing (content-type) | upload | accept | DOCS-01 допускает любой формат; MIME не валидируется в v1 (осознанно) |
| T-04-05 | Elevation of Privilege | upload / все роуты | mitigate | user_id ВСЕГДА из get_current_user JWT, НИКОГДА из тела/query |
</threat_model>
