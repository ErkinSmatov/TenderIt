<interfaces>
Backend API (из Plan 02):
- POST /api/documents (multipart: file, category, expires_at?) → DocumentResponse (201)
- GET /api/documents → DocumentResponse[]
- GET /api/documents/{id}/url → {url, expires_in}
- PATCH /api/documents/{id} (category?, expires_at?) → DocumentResponse
- DELETE /api/documents/{id} → 204

DocumentResponse shape (зеркало backend schemas/document.py):
- id, file_name, file_key, file_size, mime_type
- category: "ustav"|"license"|"certificate"|"registration"|"other"
- expires_at: string|null, uploaded_at: string
- expiry_status: "ok"|"warning_14"|"warning_7"|"expired"

Существующие хелперы/компоненты:
- frontend/src/lib/api.ts: `api.get/post/put/delete` (apiFetch с JSON Content-Type) + `BASE`, `useAuthStore`
- shadcn ui: Card/CardContent/CardHeader/CardTitle, Button, Input, Label, Alert, Badge (variants: secondary/outline/destructive)
- lucide-react: FileText, Trash2, Download (доступны)
- @tanstack/react-query: useQuery, useQueryClient
- react-hook-form + @hookform/resolvers/zod + zod

Категории (русские названия для UI):
ustav→Устав, license→Лицензия, certificate→Сертификат,
registration→Свидетельство о регистрации, other→Прочее
</interfaces>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → API | Форма шлёт multipart upload; ответы рендерятся в UI |
| browser → MinIO | Скачивание напрямую по pre-signed URL (выдан backend) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-06 | Tampering | uploadFile Content-Type | mitigate | НЕ выставлять Content-Type вручную — браузер ставит boundary; иначе парсер падает |
| T-04-03 | Information Disclosure | onDownload URL | accept | URL получен от backend (pre-signed TTL 15 мин), открывается в новой вкладке; короткий TTL ограничивает утечку |
| T-04-05 | Elevation of Privilege | upload/delete вызовы | mitigate | UI не шлёт user_id; backend берёт его из JWT cookie (credentials:'include') |
</threat_model>
