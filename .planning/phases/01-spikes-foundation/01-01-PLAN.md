<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| .env file → app config | Secrets read from disk at startup; .env must not be committed |
| Developer machine → Docker daemon | docker compose commands run with host-level daemon access |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Information Disclosure | .env file | mitigate | Add .env to .gitignore from first commit; .env.example contains only placeholder values, never real secrets |
| T-01-02 | Information Disclosure | docker-compose.yml hardcoded dev passwords | accept | Dev-only credentials (tenderit_dev, minioadmin_dev); production will use environment injection, not compose file |
| T-01-03 | Elevation of Privilege | Docker daemon access | accept | Development machine only; Docker Desktop runs with user-level permissions on macOS |
</threat_model>
