    Create backend/spikes/spike_goszakup.py — an async Python script that executes all SPIKE-01 measurements in sequence. The script reads GOSZAKUP_API_TOKEN from the environment (via os.environ or python-dotenv). If the token is not set, it prints a clear error message and exits with code 1. Do not hard-code any tokens.

    The script must perform these steps in order:

    Step 1 — Endpoint reachability check:
      POST https://ows.goszakup.gov.kz/v3/graphql with {"query": "{ __typename }"} and Authorization: Bearer {token} header.
      Record: HTTP status code, response time, whether the response body is valid JSON.
      If status is not 200, print the status and response body and stop with a clear message about what failed.

    Step 2 — Full schema introspection:
      POST the full GraphQL introspection query (paste the full query below — it is the standard introspection query from the GraphQL spec):
        { __schema { queryType { name fields { name description type { name kind ofType { name kind } } } } mutationType { name fields { name description args { name type { name kind ofType { name kind } } } } } subscriptionType { name } types { name kind description fields { name description type { name kind ofType { name kind } } } } } }
      Save the full JSON response to backend/spikes/findings/spike-01-schema.json. Use json.dump with indent=2 and ensure_ascii=False so Cyrillic field names are preserved.
      Extract and print to stdout: the queryType field names, mutationType field names (if mutationType is not null), and the names of all OBJECT types.

    Step 3 — TrdBuy live query:
      POST { TrdBuy(limit: 5) { id nameRu statusRu publishDate } }
      Record: response status, first item in the response, response time.
      Save the response to backend/spikes/findings/spike-01-trdbuy-sample.json.

    Step 4 — Rate limit probe:
      Send 15 POST requests one second apart, each with { TrdBuy(limit: 1) { id } }.
      Record for each request: request number, HTTP status code, elapsed time in milliseconds, value of Retry-After or X-RateLimit-* headers if present.
      If any request returns 429, stop immediately and record how many requests triggered the limit.
      Save results to backend/spikes/findings/spike-01-rate-limit-probe.json.

    The script must be runnable as: cd backend && GOSZAKUP_API_TOKEN=your_token python -m spikes.spike_goszakup

    Use httpx.AsyncClient with timeout=30.0 for all requests. Use asyncio.run() as the entry point. Use tenacity for the TrdBuy live query only (max 2 retries with 5 second wait) — not for the rate limit probe (where we want to measure natural behavior).

    Create backend/tests/spikes/test_spike01_goszakup.py:
      This is a smoke test that runs if GOSZAKUP_API_TOKEN is set in the environment. If the token is not set, the test is skipped with pytest.skip("GOSZAKUP_API_TOKEN not set").
      Tests:
        test_goszakup_endpoint_reachable: POST {"query": "{ __typename }"} → assert response.status_code == 200 or 401 (both mean the endpoint exists)
        test_goszakup_schema_introspectable: POST introspection query with valid token → assert "data" in response.json() and response.json()["data"]["__schema"] is not None
      Both tests use httpx.AsyncClient and are marked @pytest.mark.asyncio and @pytest.mark.skipif.

    Create docs/letter-templates/goszakup-api-token-request.md — a formal letter template in Russian for requesting an API token from АО "Центр Электронных Финансов":

      The letter must be production-quality Russian — this is a formal legal document addressed to a government-adjacent entity.
