## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01-01 | Information Disclosure | goszakup token hardcoded or logged | mitigate | Token only via settings.goszakup_api_token; grep gate forbids hardcoded Bearer literal; no logging of headers |
| T-03-01-02 | Denial of Service | Retry storm hammering goszakup on 401/403 | mitigate | _is_retryable returns False for all 4xx; only 5xx/network retried, max 3 attempts |
| T-03-01-03 | Tampering | Concurrent upsert producing duplicate tender rows | mitigate | pg_insert ON CONFLICT DO UPDATE on number_anno unique index — atomic |
| T-03-01-04 | Denial of Service | Excessive live API calls | mitigate | 30-min cache-aside: at most 2 live calls/hour per unique tender (RESEARCH security domain) |
</threat_model>
