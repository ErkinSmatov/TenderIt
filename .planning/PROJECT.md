# TenderIt

## What This Is

Единая платформа для казахстанских компаний (малый и средний бизнес) для поиска тендеров и участия в них — без ручного обхода 10 разных порталов. Директор/ИП находит релевантные тендеры, хранит документы компании, подписывает заявки ЭЦП (NCALayer) и отправляет на порталы — всё в одном интерфейсе.

## Core Value

**Подача тендерной заявки за 3 клика**: нашли → подписали ЭЦП → отправлено автоматически.

## Context

**Целевой пользователь:** Директор / ИП малого бизнеса в Казахстане, который самостоятельно занимается госзакупками. Не тендерный специалист — человек, которому некогда вручную мониторить порталы.

**Проблема:** Тендеры разбросаны по 5+ порталам. Каждый раз нужно заново загружать одни и те же документы, открывать NCALayer, вручную подписывать — это долго и утомительно.

**Решение:** Агрегатор + хранилище документов + интеграция с NCALayer + автоматическая отправка через API порталов.

**Платформы v1:**
- Госзакупки (goszakup.gov.kz) — крупнейший портал госзаказа
- MP.kz — коммерческие тендеры

**ЭЦП:** Интеграция с NCALayer через WebSocket. Пользователь устанавливает NCALayer локально, система вызывает его для подписания документов.

**Уведомления:** Telegram-бот + WhatsApp при появлении новых тендеров по фильтрам пользователя.

**Модель аккаунта:** Один аккаунт = одна компания (мультикомпания — вне скопа v1).

**Бизнес-модель:** MVP без монетизации — валидация продукта.

**Стек:** Next.js (фронтенд) + FastAPI (Python бэкенд) + PostgreSQL.

## GO / NO-GO перед запуском

**✅ Зелёный свет:**
- Фазы 1–5 завершены
- NCALayer интеграция работает (browser-only, тест на реальном ЭЦП)
- Госзакупки API принимает заявки
- Unit test coverage ≥ 70%
- Нет критичных security issues
- Документация полная (API docs, deployment guide)
- Токен от Ecc.kz получен

**❌ Красный свет:**
- ЭЦП интеграция не работает
- Госзакупки API отклоняет заявки
- Утечка паролей / токенов
- Load test не пройден (< 50 одновременных)
- Нет документации по deployment

## Риски

| Риск | Вероятность | Impact | Mitigation |
|------|------------|--------|------------|
| NCALayer не установлена на ПК пользователя | Высокая | 🔴 Блокирует | Инструкция в README + support-чат |
| Госзакупки API изменит структуру | Средняя | 🟡 Нужен fix | Монитор ошибок + быстрый response |
| Токен Госзакупок протечёт | Низкая | 🔴 Критично | .env на сервере, gitignore, rotate токены |
| Пользователь забудет пароль ЭЦП | Высокая | 🟡 UX issue | Понятная ошибка + инструкция |
| Задержка в получении токена от Ecc.kz | Средняя | 🔴 Задержка | Запросить токен на неделе 1 фазы 1 |
| MP.kz не имеет публичного API | Средняя | 🟡 Pivot | SPIKE-04 определяет подход (API vs scraping) |

## Security Constraints (обязательные)

**НИКОГДА:**
- Не сохранять пароль ЭЦП в БД
- Не логировать содержимое документов
- Не передавать пароль по незащищённому каналу
- Не хранить токен Госзакупок в коде (только .env)
- Не подключаться к NCALayer со стороны сервера (browser-only!)

**ВСЕГДА:**
- Использовать HTTPS (SSL обязателен)
- Валидировать весь input на backend
- Логировать все действия с ЭЦП (для аудита)
- Требовать явное согласие пользователя перед отправкой заявки
